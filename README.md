# HANAS-ADMIN-FE - Setup Enviroment(Quick Guide)

### 1. Clone repository in your local

```
https://github.com/TaiyoShiawase/HANAS-ADMIN-FE.git
```

### 2. Install the packages being used in this project

```
npm i
```

_Initial Packages Installed:_
- react-router-dom
- react-bootstrap
- react-icons
- js-cookie
- sass

### 3. Run the Application

```
npm start
```
